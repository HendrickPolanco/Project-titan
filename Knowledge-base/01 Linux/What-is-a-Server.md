# What is a Server?
    It's computer use for big amount of data storage that is conecting to internet and recive thousand of request from others smart devices like smartphone, laptop, tables, etc.
## Definition
    A server operates on the client-server model. It is defined by its primary function: to "serve" requests.

## Why do servers exist?

    Because perosnal divices like smartphone do not have power, storage, or security to house the massive amounts of data used globally every day.

## What problems do they solve?

Centralization of data in one secure place.
Scalability to allow a single high-perfomance machine network.
Reliability: Protects against data loss through redundant systems.

## Client vs Server
    client whom actively requests a service or data
    server the computer or program that passively listens for requests, process them, and returns responses.
## Physical Server
    Server that is tangible, hardware-based computer.

## Virtual Server
   vitual server is a siftware-baased representation of a physical computer. using virtualization software in one powerful physical server is divided into multiple independent virtual servers.
## Cloud Server
    Cloud server is avirtial server hosted on a global. internet-based infrastructure. ex: aws, azure
## Home Server
        Home server is a physical ir virtual machine located in a private residence.
## Examples
Web Server: Hosts and delivers web pages to your browser (e.g., Apache HTTP Server or Nginx).
Database Server: Stores and retrieves structured data and information.
File Server: Manages centralized file storage so multiple users can access and share documents.
DNS Server: Translates human-readable domain names (e.g., google.com) into machine-readable IP addresses.

    
## Real-world Examples
        Streaming Services: When you hit "play" on a movie, a video server transmits the data directly to your TV's app.
    Online Gaming: Game servers maintain the state of the virtual world, syncing the movements of hundreds of players simultaneously.
