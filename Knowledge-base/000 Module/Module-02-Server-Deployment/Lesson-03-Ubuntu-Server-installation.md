## Objective

Install Ubunte Server LTS on the Lenovo ThinkCentre m70q Gen 2 as the primary operationg system for Project TITAN.

## Why Ubuntu Server?

We decide use ubuntu as operating system because we can learn more about linux and how to manager a linux with command, hardware performance, ssh, third-party drive, etc. Another reason we decide use ubunte first is for learn how to migrate a server to another server or to a hyperviser like promox.

# Lessons Learned

Ubuntu Server does not include a graphical interface.

The installation process was simpler than expected.

The operating system boots directly into the terminal.

Linux servers are managed primarily through the command line.
